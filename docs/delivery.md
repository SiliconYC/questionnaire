## 未执行与限制

- 移动端使用浏览器视口与触控模拟，未接入实际手机；未验证 Safari/iOS 实机。
- Excel 使用 ExcelJS 重新打开并核对工作表、数字与字符串类型；尚未在实际 Microsoft Excel 中验证首次打开行为。CSV 不承诺跨所有表格软件绝对安全。
- SQL 的本地 PostgreSQL/WASM 冒烟中 Auth、Schema 扩展为测试替身；不代表真实 Supabase Auth、PostgREST、扩展或 RLS 验收。
- 真实 Supabase、公开 key、SMTP、独立 HTTPS 托管、负责人/服务区域/隐私告知、备份恢复与删除重放责任尚未配置。`AC-20` 至 `AC-26`、`AC-37` 的真实验收未执行。
- 没有可用受控推断服务，`AC-27` 至 `AC-32` 未执行，`inference=false`。不把描述统计包装成重复测量推断结果。
- 文件限 `5MiB` 压缩、`20MiB` 实际解压、`20000` 非空单元格与 `256` ZIP 条目，拒绝 ZIP64、多卷、加密及宏格式，正式模板不需要这些扩展。

真实环境就绪后的执行清单见 [真实服务接入](live-setup.md)。
