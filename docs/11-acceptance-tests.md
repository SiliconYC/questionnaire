# 11 · 验收标准与需求追踪

## 1. 验收原则

本章定义实现完成后必须验证的行为，不表示当前已经通过。每次交付为场景记录 `通过 / 失败 / 未执行 / 不适用`、模式、环境、源提交、证据位置和实际结果。只凭页面截图不能证明权限、跨设备同步或事务正确。

M1 可用浏览器端独立构造数据验证；M2 必须包含真实隔离后端、独立身份和直接 API 测试；M3 必须有可信统计参考。没有外部环境的场景标“未执行”，不能标“通过”。

## 2. 演示与业务闭环

| 编号 | 场景和操作 | 必须观察到的结果 | 阶段 |
| --- | --- | --- | --- |
| `AC-01` | 在无历史数据的浏览器打开 Pages，进入演示，切换管理员与评价员 | 无需外部配置；身份带演示标记；当前模式和浏览器存储说明持续可见 | M1 |
| `AC-02` | 创建本地演示身份，刷新后再进入，最后确认重置 | 新身份可获得演示任务；无真实邮件/密码；刷新保留数据；重置恢复初始状态 | M1 |
| `AC-03` | 导入合法 JSON 与等价 Excel，再分别导出并重新导入 | ID、顺序、编码 `001`、量程和文字题语义一致；未确认导入不产生实验 | M1 |
| `AC-04` | 逐个运行非法案例，并输入公式、重复表头、过大或异常压缩文件 | 返回可定位的错误；无部分写入；不静默改分数、丢字段或执行公式 | M1 |
| `AC-05` | 对 `[1,4)`、`[4,7)`、`[7,10]` 输入 `1,4,7,10`；步长 `0.5` 输入 `7.3`；运行 [小数网格示例](examples/decimal-grid-valid.json) | 档位匹配唯一；合法两位小数全部通过；离网格和三位小数拒绝；未操作滑杆仍未作答；合法 `0` 保留 | M1 |
| `AC-06` | 发布实验、分配两人、评价员接受告知后逐样品提交 | 配置冻结；只有本人任务可见；每样品回执真实生成；所有样品提交才完成 | M1/M2 |
| `AC-07` | 连续快速修改、切换样品、刷新；注入保存失败和响应乱序 | 最新成功内容可恢复；未成功内容有明确提示；旧请求不覆盖新编辑 | M1/M2 |
| `AC-08` | 同一提交双击、丢弃首次响应再以同键重试；同键改内容重放 | 同内容只一条修订并返回同回执；改内容返回幂等冲突 | M1/M2 |
| `AC-09` | 管理员退回一个已提交样品，评价员修改并重交 | 原修订保留；退回期间不计当前统计/完成数；新修订号递增，原因可查 | M1/M2 |
| `AC-10` | 未开放、恰好截止、手动关闭、归档后尝试保存/提交/退回；未开放时分配，截止后关闭、再归档 | 采集时间和状态规则在数据层阻断；截止等号不允许提交；管理操作按各自状态规则仍可成功；历史按权限查看 | M1/M2 |
| `AC-11` | 重复分配、撤销、恢复，跳过实验告知直接请求保存 | 不生成重复任务；撤销后禁写且统计排除；恢复沿用历史；未同意被拒绝 | M1/M2 |
| `AC-12` | 保存仅有标题的未完成实验草稿，再尝试发布；编辑已发布量程或删除正式实验 | 未完成草稿可恢复，发布报告待补项；已发布变更被拒绝；复制获得新 ID且不带旧答卷/分配 | M1/M2 |

## 4. 真实身份和服务器权限

| 编号 | 场景和操作 | 必须观察到的结果 | 阶段 |
| --- | --- | --- | --- |
| `AC-20` | 真实邮箱注册、OTP 验证、首次建档、退出、重登；验证码错误/过期/重发限流 | 仅提供方验证成功才有会话；新人只获评价员；拒绝和限流有中文提示；日志不含验证码 | M2 |
| `AC-21` | 匿名、评价员 A、评价员 B、管理员分别直接请求表、视图和 RPC | 权限矩阵通过；A 不能读取/更改 B 答卷、导出全站结果或自授管理员 | M2 |
| `AC-22` | 在独立设备登录同一评价员，设备一保存，设备二读取并用旧版本保存 | 能读到云端草稿；旧版本保存被拒绝；用户比较后才能覆盖 | M2 |
| `AC-23` | 真实模式断网、后端返回 500、令牌过期、账户被停用 | 无假成功；不生成本地假回执、不切演示；停用后旧令牌也不能业务读写；可重新登录恢复 | M2 |
| `AC-24` | 提交与关闭/撤销并发，分配超上限并发，事务中途失败 | 唯一合法提交或清楚拒绝；不超额、不半写；修订、计数、审计一致 | M2 |
| `AC-25` | 关闭样品名称显示，检查参与者页面和全部网络 DTO | 不返回 `admin_name` 或其他隐藏名称；改变前端样式/角色字符串也看不到 | M2 |
| `AC-26` | 修改可编辑用户元数据为管理员、停用最后管理员、访问别人的快照 | 不提升权限；最后管理员保护生效；快照越权失败 | M2 |

`AC-21` 至少检查 `SELECT/INSERT/UPDATE/DELETE` 和全部暴露 RPC 的可用角色。只测试“管理按钮没显示”不算完成。管理员读取真实数据和导出也需通过同一授权路径，不能把 secret key 注入浏览器图表页。

## 5. 进阶统计

| 编号 | 场景和操作 | 必须观察到的结果 | 阶段 |
| --- | --- | --- | --- |
| `AC-27` | 对两样品解析参考例运行正式方法 | `F=3`、`t=√3`、`epsilon=1`、原始 `p≈0.2254033307585166`；同族两项 Holm 均 `≈0.4508066615170332`；与成熟库复核 | M3 |
| `AC-28` | 正常三样品以上矩阵对照成熟库，再加入评价员整体加分偏移 | 主方法使用重复测量和 GG；结果与约定参考一致；不误把所有评分当独立样本 | M3 |
| `AC-29` | 缺一单元格、重复单元格、全常数、恒定配对差、人数不足、有序等级 | 按指标完整配对；重复为错误；退化结果 `null + 原因`；ordinal 不输出参数检验 p | M3 |
| `AC-30` | 多个 interval 指标含不可计算项，改变输入顺序但不改内容 | 计划检验族大小稳定、Holm 映射回原项正确；不可计算项内部占位但对外仍 `null`；ordinal 不计入参数族 | M3 |
| `AC-31` | 用常数轮廓、两样品、整体偏高但趋势相同的评价员做诊断 | 无定义相关不伪装成 0；相关不能代替绝对一致性；不自动剔除，不输出无依据的重测可靠性 | M3 |
| `AC-32` | 普通评价员请求进阶作业，或伪造原始矩阵、读取其他快照作业；模拟超时 | 服务器拒绝；读取被冻结的授权输入；失败有状态，重复启动不重复建作业 | M3 |

推断核对对普通有限统计量使用绝对误差 `1e-10` 或相对误差 `1e-8`，两者满足其一，与 [07](07-statistical-analysis.md) 一致。极小 p 另用相对误差或对数尺度核对，不能用宽绝对容差接受错误的 0；不以四舍五入后的 UI 文本作唯一参考。正式报告记录实现与参考库版本。描述参考使用资料内的绝对容差 `1e-10`。

## 8. 交付记录格式

每个里程碑说明以下内容即可，不把长日志贴进 README：

- 公开演示地址或真实应用地址，当前运行模式。
- 对应源提交、产物提交、数据库迁移版本、分析服务版本（适用时）。
- 已通过、失败、未执行场景及其原因；实际测试命令与环境。
- 已配置的外部服务种类，不含密钥；缺失配置与对能力的具体影响。
- 已知限制、恢复/回滚入口、后续任务。

阻塞级问题包括：无法完成主流程、丢失已确认保存内容、假成功、越权读写、静默模式切换、错误统计结论、真实敏感数据进入公开产物。上述问题未解决，不可把对应里程碑标为完成。
