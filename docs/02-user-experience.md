# 02 · 页面与交互

## 1. 视觉和布局

以清晰、可信、易读的中文工具界面为目标。默认浅色背景、低饱和强调色、稳定的字号层级；避免大面积深色和刺眼渐变。评价员页面以单列填写为主，管理员在桌面使用导航加内容区，表格较宽时提供受控横向滚动。原稿的“全部单列”不作为全站约束。

主操作位置保持稳定。保存状态、运行模式和当前样品始终可辨识；图表必须有数值表替代，颜色同时配文字/符号。基础按钮点击区域至少 `44 × 44px`，正文不小于 `16px`；这些数值是产品设计目标。

## 2. 页面清单与路由

应用使用哈希路由。真实 OAuth 回调在站点根路径查询参数中处理，处理完成后才进入哈希路由，详见 [08](08-security-and-privacy.md)。

| 路由 | 页面 | 核心内容与动作 |
| --- | --- | --- |
| `#/` | 首页 | 产品说明、演示入口、真实工作区入口、运行边界 |
| `#/auth` | 登录与注册 | 当前模式、认证入口、拒绝/失败/过期状态 |
| `#/onboarding` | 首次建档 | 昵称、评价员代号说明、隐私告知与同意 |
| `#/tasks` | 我的任务 | 待完成、已完成、退回任务；样品进度 |
| `#/tasks/:assignment_id` | 实验说明 | 实验说明、固定样品顺序、开放时间、开始/继续 |
| `#/tasks/:assignment_id/samples/:sample_id` | 样品评价 | 编码、题目、草稿状态、逐样品提交 |
| `#/records/:response_id` | 提交记录 | 修订号、提交时间、只读答卷、退回原因 |
| `#/admin` | 管理总览 | 实验状态、完成进度、待处理项 |
| `#/admin/experiments/new` | 创建实验 | 配置向导、导入、预览 |
| `#/admin/experiments/:experiment_id` | 实验工作台 | 配置、分配、进度、答卷、分析、导出 |
| `#/admin/participants` | 评价员管理 | 已激活评价员、代号、状态、任务数量 |
| `#/settings` | 设置 | 模式说明、退出、个人资料、演示重置 |

未登录访问受限页面先到认证页并保存站内目标。认证后仍需检查分配和角色；没有权限统一显示“无法访问此内容”，避免泄露其他实验是否存在。不存在的路由有返回首页入口。

## 3. 演示体验

首页按钮“体验演示”进入管理员预设身份，展示一张可关闭的引导卡：“创建或打开实验 → 切换评价员填写 → 返回管理员查看结果”。切换角色入口仅在演示工具栏出现。

演示初始数据包含：一个可编辑草稿实验、一个开放实验、一个已关闭且有合成结果的实验；三名可切换评价员，另有用于图表的合成评价记录。数据统一标注“示例数据”。

演示注册允许输入昵称和虚构邮箱标识，点击后展示“模拟验证”步骤，再创建本地身份。使用 `example.invalid` 作为示例邮箱域；不要求真实邮箱，不采集或保存密码，不发邮件。可演示重复身份、验证码过期和重新开始等界面，但这些状态由演示控制器显式生成。

固定提示文案：**“演示模式 · 数据仅保存在当前浏览器，重置或清理浏览器数据后会丢失。”** 进入不同浏览器看到各自独立数据是预期行为。重置时说明将清除本地演示实验和答卷，二次确认后一次性恢复初始数据。

## 4. 管理员创建实验

创建向导分为基本信息、样品、数值指标、文字题、预览五步。支持前后返回和保存草稿；保留输入，不因校验错误整页清空。

样品列表突出编码，可拖动或用上下按钮调整固定顺序。指标编辑包括大类、名称、说明、连续/档位形式、量程、步长、必答、无法评价开关。档位用边界表编辑，实时指出重叠、缺口和覆盖不完整。

导入界面按“选择文件 → 校验 → 错误/预览 → 确认导入”完成。错误列出工作表、单元格或 JSON 路径、问题、修正方式；返回错误后仍可下载错误清单。禁止点击上传即覆盖现有实验。

发布前集中展示配置、评价员端预览、样品名称是否可见、固定呈送顺序、开放时间。发布确认文案说明：“发布后题目与量程将锁定，后续调整请复制为新实验。”未分配评价员允许发布，但工作台给出分配入口。

## 5. 评价员填写

进入实验先阅读说明。样品导航显示“未开始 / 草稿 / 已提交 / 已退回”，不要求必须按顺序提交，但始终展示管理员定义的建议顺序。V1 不宣称记录了真实品尝顺序。

每个指标包含完整名称、说明、允许范围、数值输入和可选滑杆。滑杆显示未作答状态，只有主动操作后才产生值；输入框允许暂时处于空字符串等编辑中间态，保存时转换为规范数据。输入 `7.3` 时不能自动改成 `7` 或越界截断。命中档位时高亮对应描述，边界规则由配置规范定义。

文字题显示字数和上限，不自动润色或替换原话。“无法评价”只有被配置允许时出现，选择后清除分数并要求原因。所有必填错误在提交时集中说明，并定位首个错误；各字段同时保留就地提示。

自动保存采用停止输入 `800ms` 后保存，失焦和切换样品时尽力完成待保存内容。界面区分：

| 状态 | 显示内容 | 行为 |
| --- | --- | --- |
| 编辑未落盘 | 有未保存修改 | 可继续编辑；离开提醒 |
| 保存进行中 | 正在保存… | 不提前显示成功 |
| `demo` 成功 | 已保存到本浏览器 · 时间 | 刷新恢复 |
| `live` 成功 | 已保存到工作区 · 时间 | 其他设备可读取 |
| 保存失败 | 保存失败，内容仍在当前页面 | 保留输入，提供重试/复制内容 |
| 版本冲突 | 另一设备已更新此答卷 | 展示服务器版本与本地未保存内容，用户选择后再保存 |

`live` 不建立隐形离线同步队列。断网期间输入仅留当前页面内存，明确提示刷新可能丢失；恢复联网后重新读版本再保存，不自动覆盖远端。浏览器关闭事件不是可靠保存机制。

逐样品提交前展示确认摘要，列出未填或无法评价项。成功后显示样品编码、修订号、服务端时间、回执编号和“继续下一样品”。提交处理中禁用重复点击，但最终防重由数据层保证。

## 6. 退回、截止与任务撤销

管理员仅能在实验仍开放时退回答卷，必须填写原因。评价员看到原因与上一修订，修改后重新提交。整个实验截止后，继续输入和提交按钮均禁用，草稿仍只读可查看；迟到请求由服务端拒绝。

任务撤销后停止新填写，已提交历史不删除。管理员可恢复同一个任务，恢复后沿用原答卷而不新建重复任务；恢复仅在实验开放时允许。统计是否纳入撤销任务按数据规范固定为“不纳入”，并显示排除数量。

## 7. 分析与导出界面

分析页有“概览 / 指标分布 / 文字反馈 / 进阶分析”四个区域。默认显示当前有效数据、未完成人数和数据截止时间。重新加载后如数据变化，标记旧分析结果已过时，并允许重新生成；下载文件固定使用当前选择的分析快照。

图表的鼠标提示和数值表均显示单位、量程及有效人数。雷达图明确是否做量程归一化，不能用面积排序宣布最好样品。进阶分析未启用时显示能力说明与“当前版本未提供”，不得摆放静态的显著性星号或假 `p` 值。

导出前选择实验、数据范围与文件类型，默认不含邮箱等身份资料。下载中有进度；失败可重试；无数据时仍可导出带表头和说明的文件。文档和页面使用“下载到本机”，不虚构服务端生成或邮件发送。

## 8. 通用状态验收

每个主要页面必须具备加载、空数据、无权限、错误与重试状态。长任务可取消，取消不得保存半个实验或半份答卷。仅页面按钮禁用不够，服务层仍检查相同约束。

键盘焦点不被自动刷新抢走；模态框可按 `Esc` 关闭，关闭后焦点回到触发按钮；状态提示使用适当的无障碍公告；错误不只靠颜色传达。减少动态效果设置生效，移动端键盘弹出后仍能操作当前题目。
